# 云栖阁收藏（Chrome 浏览器插件）

在浏览网页时，一键把当前页面收藏到你家的云栖阁导航页里，不用再复制网址、切换标签页、手动添加。

## 先准备两样东西

1. **云栖阁服务器地址**：比如 `http://192.168.57.228:23000`（家里 NAS 的地址），后面不要加斜杠。
2. **Token（钥匙）**：打开云栖阁网页 → **设置 → 插件与 AI 助手的钥匙**，点"复制"即可。
   Token 是钥匙，不要发给别人。

## 安装步骤（只需要做一次）

1. 打开 Chrome，在地址栏输入 `chrome://extensions` 回车。
2. 右上角打开 **开发者模式** 开关。
3. 点左上角 **加载已解压的扩展程序**。
4. 选择本仓库的 `chrome-extension` 文件夹，点"选择文件夹"。
5. 工具栏出现云栖阁图标（枣红底、金色"栖"字），安装完成。

## 配置步骤（只需要做一次）

1. 点工具栏的云栖阁图标 → 如果还没配置，会提示你去填写。
2. 点 **去填写配置**（或右键图标 → 选项），填入上面的服务器地址和 Token，点保存。
3. 点 **测试连接**，显示"连接成功"就说明配好了。

## 怎么用

- **弹窗收藏**：在任意网页点工具栏的云栖阁图标，标题和网址会自动填好（都能改），选个分类、写句备注（可不填），点"收藏"就行。分类下拉框最后有个"＋ 新建分类"，选它可以现场起个新分类名，云栖阁会自动创建。
- **右键收藏**：在网页空白处点右键 → **收藏到云栖阁**，直接存到"浏览器收藏"分类；在某个链接上点右键 → **收藏这个链接到云栖阁**，存的是这个链接。

收藏成功后，打开云栖阁首页，对应分类里就能看到这条书签。

## 常见问题

- **提示"还没配置"**：去扩展的选项页把服务器地址和 Token 填好。
- **提示"Token 无效"**：Token 可能被重新生成过，去云栖阁"设置 → 插件与 AI 助手的钥匙"里重新复制。
- **提示"连不上服务器"**：检查 NAS 是否开机、地址是否写对、电脑和 NAS 是否在同一个局域网。
